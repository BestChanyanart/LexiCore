# รบกวนการครอบครองในที่ดินสาธารณสมบัติ

**ที่มา:** ชุดเก็งอัตนัย 41215 ละเมิดและทรัพย์สิน หน้า 38-39

## แนวตอบแบบย่อหน้า

แม้การครอบครองสาธารณสมบัติของแผ่นดินจะใช้ยันรัฐไม่ได้ แต่ในความสัมพันธ์ระหว่างราษฎรด้วยกัน ผู้ครอบครองทำประโยชน์อยู่ก่อนยังอาจยกการครอบครองขึ้นยันผู้ที่เข้ามารบกวนโดยมิชอบได้ จึงควรวินิจฉัยว่าดินมีทางขอให้ปลดเปลื้องการรบกวนการครอบครองต่อแดนได้

## โครงสร้างคำตอบ

- ระบุประเด็นการรบกวนการครอบครอง
- อธิบายมาตรา 1374
- แยกผลต่อรัฐกับผลระหว่างราษฎร
- สรุปว่าดินยกข้อต่อสู้ต่อแดนได้
