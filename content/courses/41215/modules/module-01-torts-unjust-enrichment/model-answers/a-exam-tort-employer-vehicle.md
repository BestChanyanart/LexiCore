# แนวเฉลย

1. นาย ก. ขับรถโดยประมาทจนรถนาย ข. เสียหาย จึงควรวิเคราะห์ละเมิดตามมาตรา 420 ได้แก่ การกระทำโดยประมาท ความเสียหาย และเหตุสัมพันธ์
2. บริษัทเป็นนายจ้าง หากนาย ก. ขับรถส่งสินค้าตามงานที่มอบหมาย การกระทำเกิดในทางการที่จ้าง จึงพิจารณาความรับผิดนายจ้างตามมาตรา 425
3. รถเป็นยานพาหนะอันเดินด้วยกำลังเครื่องจักรกล จึงควรกล่าวถึงมาตรา 437 เพื่อพิจารณาผู้ครอบครองหรือควบคุมดูแล
4. สรุป นาย ก. ต้องรับผิดฐานละเมิด และบริษัทมีแนวโน้มต้องร่วมรับผิดหากพิสูจน์ว่าเหตุเกิดในทางการที่จ้าง
