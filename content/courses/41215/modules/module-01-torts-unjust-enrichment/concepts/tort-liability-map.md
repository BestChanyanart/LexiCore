# แผนผังฐานความรับผิดละเมิด

ใช้แยกฐานความรับผิดเบื้องต้นก่อนเลือกมาตรา:

- ผู้กระทำทำเอง: มาตรา 420, 423, 428, 432
- บุคคลอื่นทำ แต่กฎหมายให้รับผิด: มาตรา 425, 429
- ความเสียหายเกิดจากทรัพย์หรือสิ่งของ: มาตรา 433, 434, 437

แนวคิดหลักในการฝึก:

- แยกผู้กระทำ ผู้ต้องรับผิด และผู้เสียหาย
- ดูว่าความรับผิดเกิดจากการกระทำของตนเอง บุคคลอื่น หรือทรัพย์
- จับข้อยกเว้นหรือเหตุลด/ยกเว้นความรับผิดให้ได้
